# Project Maven vs MAEZ — Performance Comparison

**Date:** 2026-04-05 | **Author:** Perplexity Computer × MAE
**Purpose:** Structural comparison of military AI targeting (Maven) and cognitive AI decision support (MAEZ)

---

## Architecture Comparison

| Component | Maven (Military) | MAEZ (Cognitive) |
|---|---|---|
| Data Sources | 150+ (satellite, drone, radar, SIGINT, IR, HUMINT) | 5-10 (Notion, Canvas, Gmail, Calendar, GitHub, Discord, Fieldy) |
| Fusion Engine | Palantir Maven Smart System | OpenClaw + Perplexity Computer |
| Classification | Computer vision + ML object detection | SIGIL tagging + doctrine classification |
| Recommendation | Weapon-platform assignment, munition selection | 4-block template (Insight, Action, Risk, Priority) |
| Decision Speed | Kill chain: 24 hrs → 86 seconds | Cognitive chain: hours → minutes |
| Human Oversight | "Approve/deny" under time pressure | Commander confirms via [COMMIT] with [VOW] check |
| Error Rate | Even 1% at scale = catastrophic (168+ civilians in one incident) | Low stakes but drift accumulates without [DRIFT] checks |
| Ethical Framework | IHL/LOAC (contested compliance) | SIGMA LOCK + Red Line Protocol (immutable) |
| Accountability | Institutional ("the system recommended it") | Personal (Commander owns all decisions) |
| Transparency | Classified, opaque | Open doctrine, auditable Gold Codes |

## What Maven Does Better
1. **Throughput** — 80 targets/hour vs 30 without AI. 20 operators matching 2,000-person legacy cell.
2. **Multi-source fusion** — 150+ feeds into single interface. MAEZ has ~10.
3. **Automated prioritization** — Ranks targets by military value. MAEZ ranks by NOW/SOON/LATER/IGNORE (simpler but similar pattern).
4. **Institutional scale** — Deployed across all combatant commands. MAEZ serves one Commander.

## What MAEZ Does Better
1. **Ethics by design** — SIGMA LOCK is immutable. Maven's ethical constraints are policy-based (can be waived — and were, by Hegseth's Barrier Removal Board).
2. **Human-in-the-loop for real** — Commander has genuine decision time, not 86-second approve/deny under cognitive load.
3. **Transparency** — Gold Codes, OOL Triangle, and doctrine are visible and auditable. Maven is classified.
4. **Error recovery** — Low stakes mean mistakes are correctable. Maven's mistakes kill people.
5. **Personal accountability** — One Commander, one system. No diffusion of responsibility.

## Key Metrics

| Metric | Maven | MAEZ |
|---|---|---|
| Decision Speed | ~86 seconds per target | Minutes per decision |
| Daily Throughput | 300-500 strikes/day | 10-50 decisions/day |
| Data Sources | 150+ | 5-10 |
| Known Failures | 168+ civilians (Minab school), investigation ongoing | Drift accumulation, over-storage |
| Ethical Override | Policy-waivable | SIGMA LOCK (immutable) |
| Cost of Error | Human lives | Time, attention, missed deadlines |

## The Lesson

Maven proves the fusion → recommendation → action pipeline works at industrial scale.
MAEZ proves it can work at personal scale with ethical constraints intact.

The gap: MAEZ needs to stop being a storage system and start being a recommendation engine. The 4-block template + frozen tag set is the first step.

The warning: speed without guardrails killed 168 children. MAEZ must never optimize for throughput at the expense of the [VOW] check.
