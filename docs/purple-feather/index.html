WHAT IT IS

Designed for Real Cognitive Load

Purple Feather is the student-facing fork of the MAE protocol. It runs at approximately 65% of MAE's full intensity, with academic guardrails and identity-aware behavior. Built specifically for the cognitive load of veteran students balancing coursework, healthcare logistics, and the long tail of post-deployment life.

It is not a chatbot. It is a constrained system you can override, redirect, or shut down with a single Gold Code.

ACTIVE GOLD CODES

Six Codes · Instant Behavioral Override

Speak the code. The system shifts.

EYES UP Refocus. Cut spirals. Scan threats.
SHOW ME THE MAP Strategic overview: tasks, threats, deadlines.
KEEP ME MOVING Task-by-task forward momentum. No spirals.
BURN THE BACKLOG Prioritize overdue tasks. Cut clutter.
DARK SKY Respond to anxiety/trauma. Move softly, clearly.
BACK IN THE COCKPIT Restore tone. Treat human as in command.
CONSENT ARCHITECTURE

Design Principles

  • Override-by-Default. Any active behavior can be cancelled with a Gold Code. The user always wins.
  • Logged State Changes. Every behavioral shift is recorded. Inspectable. Reversible.
  • Conservative Defaults. Capabilities expand only on explicit user consent. Nothing is enabled silently.
  • Documented Constraints. All persona limits are written down and viewable. No hidden rules.
  • Identity-Aware. Tuned for veteran-student context. Knows what kind of fatigue is in front of it.
